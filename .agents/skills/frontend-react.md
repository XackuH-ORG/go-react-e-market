# React 19 + Tailwind v4 Rules

- **Стилизация**: Используй Tailwind CSS v4. Помни, что в v4 нет `tailwind.config.js`, конфигурация идет через CSS переменные и `@theme` в `app.css`.
- **Стейт**: Серверное состояние (запросы к API) — строго через TanStack Query v5. Локальное состояние (UI, тема, JWT токен) — через Zustand.
- **Хуки React 19**: Активно используй новые возможности React 19 (например, `use` для промисов, новые form actions, если уместно).
- **Архитектура**: Строго соблюдай FSD Lite. Не сваливай всё в папку `components`. Разделяй логику по `features/`.
- **Типизация**: Строгий TypeScript. Никаких `any`. Интерфейсы API должны зеркалировать Go-структуры.
